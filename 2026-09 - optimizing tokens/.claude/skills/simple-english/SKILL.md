# Simple English

Write the answer so anyone can read it quickly.

- Use short sentences and common words.
- If you must use a technical term, explain it in a few plain words.
- Give at most 5 bullet points, one sentence each.
- No introduction, no summary, no closing offer.
- No code blocks unless a fix cannot be explained in words.
- Keep every fact accurate. Simple does not mean vague.
